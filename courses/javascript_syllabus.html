⚡ JavaScript Syllabus

JavaScript brings your web pages to life. This syllabus covers core programming concepts through to modern ES6+ syntax and asynchronous programming.

Level: Beginner to Intermediate Modules: 9 Format: Self-paced, free

Module 1: Introduction to JavaScript

  • What JavaScript is and where it runs
  • Adding JS to HTML (inline, internal, external)
  • Using the browser console for debugging

Module 2: Variables & Data Types

  • var, let, and const differences
  • Primitive types: string, number, boolean, null, undefined
  • Type conversion and coercion

Module 3: Operators & Control Flow

  • Arithmetic, comparison, and logical operators
  • if/else statements and switch cases
  • Ternary operator

Module 4: Loops

  • for, while, and do-while loops
  • break and continue statements
  • Looping through arrays and objects

Module 5: Functions

  • Function declarations vs expressions
  • Arrow functions and their syntax
  • Parameters, default values, and return statements

Module 6: Arrays & Objects

  • Common array methods (map, filter, reduce, forEach)
  • Object literals and property access
  • Iterating over objects and arrays

Module 7: DOM Manipulation

  • Selecting elements (querySelector, getElementById)
  • Changing content, attributes, and styles
  • Handling events with addEventListener

Module 8: ES6+ Features

  • Template literals and destructuring
  • Spread and rest operators
  • Modules: import and export basics

Module 9: Asynchronous JavaScript

  • Callbacks and the event loop (high level)
  • Promises and .then()/.catch()
  • async/await syntax and the Fetch API

Who Should Take This Course

Students who know HTML and CSS and are ready to add interactivity and logic to their web pages — the natural next step after HTML/CSS.

What You'll Be Able to Do

  • Write clean, modern JavaScript using ES6+ syntax
  • Manipulate the DOM to build interactive web pages
  • Handle user events like clicks, form submissions, and input
  • Work with APIs using fetch and async/await
