☕ Java Syllabus

Java is one of the most widely used languages for backend development and technical interviews. This syllabus covers core syntax through to object-oriented programming and collections.

Level: Beginner to Intermediate Modules: 8 Format: Self-paced, free

Module 1: Introduction to Java

  • Understanding JVM, JDK, and JRE
  • Setting up your development environment
  • Writing and running your first Java program

Module 2: Variables & Data Types

  • Primitive data types (int, float, char, boolean)
  • Type casting and conversion
  • Constants and variable scope

Module 3: Operators & Control Statements

  • Arithmetic, relational, and logical operators
  • if/else and switch statements
  • for, while, and do-while loops

Module 4: Object-Oriented Programming Basics

  • Classes and objects
  • Constructors and the 'this' keyword
  • Methods and method overloading

Module 5: The Four Pillars of OOP

  • Inheritance and the 'extends' keyword
  • Polymorphism (overriding vs overloading)
  • Encapsulation with access modifiers
  • Abstraction with abstract classes and interfaces

Module 6: Arrays & Strings

  • Declaring and using single/multi-dimensional arrays
  • Common String class methods
  • StringBuilder for efficient string manipulation

Module 7: Collections Framework

  • ArrayList and LinkedList basics
  • HashMap and HashSet fundamentals
  • Choosing the right collection for the job

Module 8: Exception Handling

  • try, catch, and finally blocks
  • Checked vs unchecked exceptions
  • Creating custom exceptions

Who Should Take This Course

Students preparing for placements where Java is commonly tested, and anyone who wants a strong foundation in object-oriented programming.

What You'll Be Able to Do

  • Write object-oriented Java programs from scratch
  • Apply the four pillars of OOP confidently
  • Use Java's Collections Framework effectively
  • Handle errors gracefully with exception handling
