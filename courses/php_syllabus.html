🐘 PHP Syllabus

PHP powers a huge portion of the web's server-side logic. This syllabus takes you from basic syntax to connecting your pages with a real database.

Level: Beginner to Intermediate Modules: 8 Format: Self-paced, free

Module 1: Introduction to PHP

  • What PHP is and how server-side scripting works
  • Setting up a local server environment (e.g. XAMPP)
  • Writing and running your first PHP script

Module 2: PHP Syntax Basics

  • Variables and data types
  • echo and print statements
  • Comments and code structure

Module 3: Operators & Control Structures

  • Arithmetic, comparison, and logical operators
  • if/else and switch statements
  • for, while, and foreach loops

Module 4: Functions

  • Built-in PHP functions
  • Writing user-defined functions
  • Default arguments and return values

Module 5: Arrays

  • Indexed arrays
  • Associative arrays
  • Multidimensional arrays and common array functions

Module 6: Working with Forms

  • GET vs POST methods
  • Reading form data with $_GET and $_POST
  • Basic input validation and sanitization

Module 7: Sessions & Cookies

  • Starting and using sessions
  • Setting and reading cookies
  • Basic login-state management concepts

Module 8: MySQL Database Connectivity

  • Connecting to MySQL with mysqli/PDO
  • Running basic SELECT, INSERT, and UPDATE queries
  • Displaying database results on a web page

Who Should Take This Course

Students who already know HTML and want to learn server-side scripting, and anyone interested in building dynamic, database-driven websites.

What You'll Be Able to Do

  • Write server-side PHP scripts to process form data
  • Manage user sessions and basic authentication state
  • Connect PHP to a MySQL database and run queries
  • Build a simple, functional dynamic web application
