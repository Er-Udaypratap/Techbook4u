🎨 CSS Syllabus

CSS turns plain HTML into a designed, responsive experience. This syllabus covers everything from basic selectors to modern layout systems like Flexbox and Grid.

Level: Beginner Modules: 9 Format: Self-paced, free

Module 1: Introduction to CSS

  • What CSS is and how it works with HTML
  • Inline, internal, and external stylesheets
  • Basic CSS syntax and rule structure

Module 2: Selectors

  • Element, class, and ID selectors
  • Attribute and pseudo-class selectors
  • Combinators and selector specificity

Module 3: The Box Model

  • Content, padding, border, and margin
  • box-sizing: border-box vs content-box
  • Width, height, and overflow behavior

Module 4: Colors & Typography

  • Color formats: hex, rgb, hsl
  • Font properties and web fonts
  • Text alignment, spacing, and line-height

Module 5: Layout Basics

  • The display property (block, inline, inline-block)
  • Positioning: static, relative, absolute, fixed
  • z-index and stacking context

Module 6: Flexbox

  • Flex containers and flex items
  • justify-content, align-items, and flex-direction
  • Building common layouts with Flexbox

Module 7: CSS Grid

  • Grid containers, tracks, and template areas
  • Building multi-column responsive layouts
  • Combining Grid and Flexbox effectively

Module 8: Responsive Design

  • Media queries and breakpoints
  • Mobile-first design approach
  • Relative units: %, vw/vh, rem, em

Module 9: Animations & Transitions

  • The transition property
  • @keyframes and the animation property
  • CSS transforms (scale, rotate, translate)

Who Should Take This Course

Anyone who has a basic grasp of HTML and wants to learn how to style, layout, and make their pages responsive across devices.

What You'll Be Able to Do

  • Style any HTML page with confidence using modern CSS
  • Build responsive layouts with Flexbox and CSS Grid
  • Create smooth hover effects and animations
  • Design mobile-friendly pages that adapt to any screen size
