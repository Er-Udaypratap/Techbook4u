🌐 HTML Syllabus

HTML is the foundation of every website. This syllabus takes you from your very first tag to building fully structured, semantic web pages.

Level: Beginner Modules: 7 Format: Self-paced, free

Module 1: Introduction to HTML

  • What HTML is and how browsers render it
  • Setting up a code editor and creating your first HTML file
  • Understanding the basic document structure (doctype, html, head, body)

Module 2: Text & Basic Tags

  • Headings (h1–h6) and paragraphs
  • Bold, italic, and other text formatting tags
  • Ordered and unordered lists
  • Comments and code readability

Module 3: Links & Navigation

  • Anchor tags and href attributes
  • Relative vs absolute URLs
  • Building a basic navigation menu

Module 4: Images & Media

  • The img tag and alt attribute for accessibility
  • Embedding audio and video
  • Image formats and basic optimization tips

Module 5: Tables

  • Table, row, and cell structure (table, tr, td, th)
  • Table headers and captions
  • When to use (and not use) tables for layout

Module 6: Forms

  • Form element and common input types
  • Labels, placeholders, and required fields
  • Buttons, dropdowns, and checkboxes
  • Basic client-side validation attributes

Module 7: Semantic HTML5

  • header, nav, main, section, article, footer
  • Why semantic markup matters for SEO and accessibility
  • Structuring a complete, real-world page layout

Who Should Take This Course

Absolute beginners with no prior coding experience, students starting web development, and anyone who wants to understand how web pages are structured before moving on to CSS and JavaScript.

What You'll Be Able to Do

  • Build a complete, well-structured web page from scratch
  • Create accessible forms and navigation menus
  • Use semantic HTML5 elements the way modern websites do
  • Move confidently into styling your pages with CSS
