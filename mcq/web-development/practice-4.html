Question 1 of 10

Which CSS property is used to create a flexbox container?

Setting display: flex; on a container turns its children into flex items.
Question 2 of 10

Which property controls the direction of flex items?

'flex-direction' sets whether flex items lay out in a row or column.
Question 3 of 10

Which CSS layout system is designed for two-dimensional layouts (rows and columns)?

CSS Grid is built specifically for two-dimensional row-and-column layouts.
Question 4 of 10

Which position value removes an element from normal document flow and positions it relative to its nearest positioned ancestor?

position: absolute; takes the element out of flow, positioned relative to the nearest positioned ancestor.
Question 5 of 10

What is the default value of the 'position' property?

By default, all elements have position: static, following normal document flow.
Question 6 of 10

Which property is used to create equally spaced columns in CSS Grid?

'grid-template-columns' defines the number and size of columns in a grid container.
Question 7 of 10

What does 'position: fixed' do?

Fixed positioning keeps an element in the same place relative to the browser window, even while scrolling.
Question 8 of 10

Which media query targets screens smaller than 768px?

max-width: 768px applies styles to viewports 768px wide or narrower.
Question 9 of 10

Which property aligns flex items along the main axis?

'justify-content' controls alignment of flex items along the main axis.
Question 10 of 10

What does 'box-sizing: border-box' do?

border-box makes width/height calculations include padding and border, simplifying sizing.
