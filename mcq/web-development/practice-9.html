Question 1 of 10

Which tag is used to define the page's meta description for SEO?

The meta description tag summarizes page content for search engine results.
Question 2 of 10

What does 'lazy loading' images help with?

Lazy loading defers loading of offscreen images until they're needed, improving initial load time.
Question 3 of 10

Which HTML attribute enables native lazy loading for images?

The loading='lazy' attribute tells the browser to defer loading offscreen images.
Question 4 of 10

What is the purpose of a canonical URL tag?

A canonical tag tells search engines which URL is the 'master' copy to avoid duplicate content issues.
Question 5 of 10

Which HTTP status code indicates a page was not found?

404 Not Found indicates the requested resource does not exist on the server.
Question 6 of 10

What does minifying CSS/JS files do?

Minification strips whitespace, comments, and shortens names to reduce file size for faster loading.
Question 7 of 10

Which attribute prevents a script from blocking HTML parsing while loading?

The async and defer attributes let scripts load without blocking HTML parsing.
Question 8 of 10

What is the primary purpose of using heading tags (h1-h6) correctly?

Proper heading structure helps both users and search engines understand content organization.
Question 9 of 10

Which technique combines multiple CSS/JS files to reduce HTTP requests?

Bundling combines multiple files into fewer files, reducing the number of network requests.
Question 10 of 10

What does a sitemap.xml file help with?

A sitemap lists a website's URLs to help search engines crawl and index the site efficiently.
